# NHS Quality and Outcomes Framework

The Need Index uses the 2024/25 national practice workbook to create depression and mental health (SMI) extracts for Lincolnshire, North Lincolnshire, North East Lincolnshire, Greater Lincolnshire, Nottinghamshire, Derbyshire, and the Lincolnshire-Nottinghamshire-Derbyshire area. Practice lists include active ODS GP locations whose postcodes fall within each map boundary and every practice with patients registered in an LSOA within that boundary. July 2026 registration-to-LSOA records provide allocation weights. A missing prescribing row does not remove a practice's available QOF data.

Regenerate the county files with `scripts/utils/process_county_need_index_inputs.py`.

[NHS Digital Quality and Outcomes Framework 2024-25](https://digital.nhs.uk/data-and-information/publications/statistical/quality-and-outcomes-framework-achievement-prevalence-and-exceptions-data/2024-25)
