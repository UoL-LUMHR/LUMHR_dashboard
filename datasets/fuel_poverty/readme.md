## Lincolnshire extract

The 2024 LSOA extract is in [2024/lincolnshire_fuel_poverty_2024.csv](2024/lincolnshire_fuel_poverty_2024.csv). It contains the 435 LSOAs represented by the Lincolnshire 2021 LSOA GeoJSON and was generated from the LSOA table in the source workbook with [extract_lincolnshire_fuel_poverty.py](../../scripts/utils/extract_lincolnshire_fuel_poverty.py).
