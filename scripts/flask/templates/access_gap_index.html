Access Gap Index

Adjust weights to recalculate LSOA access gap indices.

Method Summary

The Access Gap Index highlights LSOAs where mental health need is high relative to service accessibility.

Formula:

  • Access Gap Index = Need Index − Access Index
  • Both the Need Index and the Access Index are independently normalised composite scores in [0,1], each with their own weight sliders below.
  • Positive values indicate need outpacing access (a potential access gap); negative values indicate access exceeding need.
Data Sources

  • GP Patient Registration (July 2026, NHS Digital) — GP registration coverage & list inflation
  • QOF Mental Health & Depression Prevalence and Achievements (2024-25, NHS Digital)
  • Antidepressant Prescribing (OpenPrescribing)
  • Small Area Mental Health Index (SAMHI, PLDR)
  • Journey Time Statistics (DfT, 2019)
  • Rural Urban Classification (2021, DEFRA / ONS)
  • Car or Van Availability (Census 2021 TS045, ONS)
  • Digital Exclusion Risk Index (DERI v1.6, GMCA)
