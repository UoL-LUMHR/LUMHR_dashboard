Public SAMHI-3

A public data proxy for mental-health need.

Not official SAMHI. This index uses antidepressant prescribing, QOF depression and DLA/PIP only. The safeguarded hospital-attendance component is unavailable.
Method summary
  • Each available component is standardised against its 2011-2022 reference mean and standard deviation.
  • The three z-scores are combined with equal weights. Hospital attendances are not imputed, so this is a proxy rather than the official SAMHI.
  • Forecasts use lagged components and the previous proxy value; Bayesian Ridge also reports an approximate 95% prediction interval.
  • Out-of-time model forecasts begin in 2017; 2011–2016 are retained as training history and are not shown as fitted backcasts.
  • Validation is rolling-origin and reports RMSE, MAE and directional accuracy. The displayed model is not a clinical risk score.
  • The SAMHI-3 vs SAMHI map standardises both indices within each year before subtraction; it is available only for the 2011–2022 published-SAMHI overlap.
Data Sources
  • OpenPrescribing / NHS prescribing data antidepressant prescribing.
  • NHS England QOF depression prevalence allocated to LSOAs using the register/population crosswalk.
  • DWP Stat-Xplore DLA and PIP claims for mental-health/learning-difficulty reasons.
  • PLDR SAMHI published SAMHI benchmark for 2011-2022 where available.
